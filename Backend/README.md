# CourseFlow AI — Backend

**Intelligent Student Course Allocation & Analytics System**

FastAPI (Python) backend with SQLAlchemy ORM and Gemini AI integration.

## Quick Start

```bash
pip install -r requirements.txt
python seed_data.py        # Populate sample data
uvicorn main:app --reload  # http://localhost:8000/docs
```

Default credentials: **admin / admin123**
